# theRmalUAV: Clean and correct thermal UAV data

This package is designed to correct thermal UAV data. It comprises data
cleaning, image reduction, caluclating overlap, atmospheric corrections,
accounting for temperature fluctuations during the flight, emissivity
corrections ect. The corrected data will be stored as tiff-file with
updated exifdata, ready to implement in commercial photogrammetry
softwares. It furthermore provides the opportunity to optimize thermal
camera positions using coregistrated high resolution cameras.
